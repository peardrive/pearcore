# Profiles

Profiles let peers publish public identity information and discover profiles shared within spaces. Profile data is stored locally and distributed through the profile protocol.

::: info In progress
The profile API reference is being expanded. In the meantime, start from the source:
:::

- `src/services/profile.service.ts` - public profile operations
- `src/protocols/profile.protocol.ts` - peer-to-peer profile protocol
- `src/database/schemas/profile.schema.ts` - local profile storage

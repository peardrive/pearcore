---
layout: home
description: PearCore is a modular peer-to-peer framework for building decentralized applications with accounts, encrypted spaces, messaging, and file sharing.

features:
  - title: Account Identity
    details: Local keypairs, password-protected credentials, BIP39 recovery, and session-based authentication.
  - title: Encrypted Spaces
    details: Discoverable topics with read and broadcast permissions, whitelists, and shareable invite links.
  - title: Peer-to-Peer Messaging
    details: Route messages between peers that share a space and reconcile history with negentropy sync.
  - title: File Sharing
    details: Content-addressed trees, multi-source downloads, chunk scheduling, and progress events.
---

## Explore the documentation

Start with the [Quick Start](/examples), then learn how the core pieces fit together:

- [Accounts](/accounts) - create, authenticate, recover, and manage identities
- [Spaces](/spaces) - create topics, set permissions, and share invite links
- [Networking](/networking) - peer discovery, connections, and topic routing
- [Messaging](/messages) - send and synchronize messages across spaces
- [File Sharing](/files) - upload, download, and monitor transfers
- [Profiles](/profiles) - publish and discover public profile information

For the lower-level services and managers, see the [Core Services](/core-services) overview.
